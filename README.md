## Что нужно заранее

- Компьютер использует Windows x64.
- Пользователь устанавливает Autodesk Revit 2019 или Revit 2023.
- Пользователь устанавливает Codex через [официальное приложение OpenAI для Windows](https://learn.chatgpt.com/docs/app/windows).
- Пользователь имеет аккаунт ChatGPT и доступ к выбранной модели Codex.

**Текущий прототип принимает только Codex `0.164.0-alpha.11.1` с проверенной контрольной суммой.**
Новая версия приложения OpenAI может содержать другую версию Codex.
Пользователь проверяет совместимость перед установкой на другой компьютер.
Установщик RevitOKO не включает Codex и Autodesk Revit.
Пользователю не нужны Python, Node.js, .NET SDK или API-ключ OpenAI.

## Установка

1. Пользователь закрывает Revit и RevitOKO после сохранения своей работы.
2. Пользователь скачивает `RevitOKO-Windows-Dialog-Recovery.zip`.
3. Пользователь полностью распаковывает архив в обычную папку.
4. Пользователь открывает папку `artifacts\host` внутри распакованного архива.
5. Пользователь запускает `RevitOKO.Setup.exe` и нажимает «Установить».
6. Установщик создаёт ярлык **RevitOKO** на рабочем столе.
7. Пользователь открывает ярлык **RevitOKO**.
8. Пользователь выполняет вход ChatGPT при первом запуске.

Пользователь также может запустить `Install-RevitOKO.cmd` из корня распакованного архива.
Этот файл запускает EXE напрямую и не требует изменения политики PowerShell.
Пользователь сохраняет весь комплект вместе.
Пользователь не использует автоматически созданные архивы **Source code** для установки.

## Первый запрос

> Открой модель C:\Models\Project.rvt и посчитай листы. Не сохраняй модель.

Пользователь отправляет запрос кнопкой «Отправить» или сочетанием **Ctrl+Enter**.
Агент самостоятельно запускает Revit и открывает указанную модель.
Агент анализирует отдельную отсоединённую копию совместной модели.
Revit может запросить разрешение загрузить неподписанное дополнение RevitOKO.
Пользователь выбирает «Загрузить один раз» для дополнения RevitOKO.
Приложение самостоятельно обрабатывает известное предупреждение об отсутствующих связях.
