# RevitOKO

RevitOKO предоставляет отдельное окно чата для работы с моделями Revit через Codex.
Пользователь запускает RevitOKO через ярлык рабочего стола.

## Что скачать коллегам

Пользователь скачивает [RevitOKO-Windows-SDK-Autonomy.zip](https://github.com/Smailkiller/RevitOKO-downloads/releases/latest/download/RevitOKO-Windows-SDK-Autonomy.zip).
Коллеги могут скачать этот архив без аккаунта GitHub.
Пользователь также может открыть [страницу последнего релиза](https://github.com/Smailkiller/RevitOKO-downloads/releases/latest).
Архив содержит приложение, установщик и дополнения Revit.
Пользователь выбирает готовый ZIP из раздела **Assets**.
Архивы **Source code** не устанавливают приложение.

## Требования

- Компьютер использует Windows x64.
- Компьютер содержит установленный Autodesk Revit 2019 или Revit 2023.
- Компьютер содержит установленный Codex для Windows.
- Пользователь имеет аккаунт ChatGPT с доступом к Codex.
- Компьютер имеет доступ к интернету для работы Codex.

Пользователь получает Codex через [официальную страницу OpenAI](https://openai.com/codex/).
Установщик RevitOKO не устанавливает Codex и Autodesk Revit.
Пользователю не нужны Python, Node.js, .NET SDK или API-ключ OpenAI.
Приложение проверяет фактическое подключение Codex без привязки к одной версии исполняемого файла.

## Установка

1. Пользователь сохраняет свою работу и закрывает RevitOKO и Revit.
2. Пользователь полностью распаковывает `RevitOKO-Windows-SDK-Autonomy.zip` в обычную папку.
3. Пользователь запускает `Install-RevitOKO.cmd` из корня распакованной папки.
4. Пользователь нажимает **«Установить»** в окне установщика.
5. Установщик копирует приложение и добавляет дополнения для установленных Revit 2019 и Revit 2023.
6. Установщик создаёт ярлык **RevitOKO** на рабочем столе.
7. Пользователь открывает RevitOKO через ярлык.
8. Приложение находит Codex и проверяет подключение.
9. Пользователь выполняет вход ChatGPT внутри RevitOKO при первом запуске.

Пользователь также может запустить `artifacts\host\RevitOKO.Setup.exe` внутри распакованного архива.
Пользователь сохраняет весь комплект вместе и не переносит установщик отдельно.
Установщик запускается напрямую и не требует изменения политики PowerShell.
Revit может запросить разрешение при первой загрузке неподписанного дополнения RevitOKO.
Пользователь проверяет имя дополнения RevitOKO и выбирает **«Загрузить один раз»**.

## Первый запрос

Пользователь вводит запрос с полным путём к модели:

> Агент, открой модель C:\Models\model.rvt и посчитай листы. Агент не должен сохранять модель.

Пользователь нажимает **«Отправить»** или **Ctrl+Enter**.
Агент самостоятельно запускает Revit, открывает указанную модель и возвращает результат в чат.
Агент использует отдельную отсоединённую копию совместной модели для анализа.
Приложение автоматически продолжает открытие копии при известном предупреждении об отсутствующих связях.

Пользователь может запросить изображение:

> Агент, создай изображение подходящего 3D-вида модели C:\Models\model.rvt. Геометрия модели должна занимать основную часть кадра.

Приложение показывает PNG внутри ответа и предоставляет кнопку **«Открыть файл»**.
Пользователь раскрывает **«Технический отчёт»** для просмотра фактических действий и ошибок.
Пользователь может выделять текст сообщений и копировать его через **Ctrl+C**.

Пользователь также может указать прямую HTTPS-ссылку на файл RVT.
Ссылка должна возвращать файл без отдельной авторизации на странице облачного диска.

## Возможности сборки

- Агент подсчитывает листы, включая листы-заготовки.
- Агент читает сведения модели, элементы, параметры, виды и существующие спецификации.
- Агент экспортирует данные и изображения через Revit API.
- Агент выполняет код Revit API, когда готовая команда не покрывает задачу.
- Агент использует штатные инструменты Codex и настроенные MCP для дополнительных действий.
- Приложение хранит переписку и фактические технические отчёты на компьютере пользователя.

Агент выполняет код Revit API с правами текущего пользователя Windows.
Операции чтения и экспорта откатывают свою группу транзакций.
Пользователь запрашивает изменения модели отдельной задачей.
Приложение не переносит подключения MCP и профиль Codex Desktop автоматически.
Администратор отдельно настраивает необходимые MCP в профиле RevitOKO.

## Проверка сборки

Проверяющий выполнил живой сценарий в Revit 2023.1.1 **27 октября 2026 года**.
Агент открыл копию совместной модели и автоматически обработал предупреждение об отсутствующих связях.
Агент создал PNG существующего 3D-вида размером **1600 × 700 пикселей** через чат.
Проверяющий подтвердил изображение, контрольную сумму файла и крупную геометрию в кадре.
Отдельный запрос Revit API вернул **42 существующих 3D-вида** без пересборки приложения.
Обе операции подтвердили откат транзакций.
Проверяющий подтвердил неизменность исходной модели и отсутствие команд сохранения или синхронизации в журнале.
Независимый QA подтвердил **442 теста**.
Проверяющий не выполнял этот живой сценарий в Revit 2019.
Проверяющий не выполнял живую проверку изменений модели.

## Обновление и данные

Пользователь закрывает RevitOKO и Revit перед повторным запуском установщика.
Установщик сохраняет профиль ChatGPT и журналы приложения.
Приложение устанавливается в `%LOCALAPPDATA%\Programs\RevitOKO`.
Приложение хранит профиль, переписку и рабочие данные в `%LOCALAPPDATA%\RevitOKO`.
Приложение сохраняет изображения в `%LOCALAPPDATA%\RevitOKO\exports`.
Установщик размещает дополнения в `%APPDATA%\Autodesk\Revit\Addins\2019` и `2023`.
Пользователь сохраняет журнал через кнопку **«Сохранить журнал»**.
Пользователь проверяет содержимое журнала перед передачей другим людям.

## Исходники и сборка

Разработчик с доступом открывает приватный репозиторий [Smailkiller/RevitOKO](https://github.com/Smailkiller/RevitOKO).
Репозиторий содержит исходники по папкам `src`, `tests`, `launcher`, `.github` и `docs`.
Разработчик устанавливает .NET 8 SDK и запускает `Build-RevitOKO.cmd` из корня проекта.
Сценарий создаёт полный комплект Windows x64 в папке `artifacts`.
Сборка использует пакет `Revit_All_Main_Versions_API_x64` для Revit 2019 и Revit 2023.
Публичный репозиторий [RevitOKO-downloads](https://github.com/Smailkiller/RevitOKO-downloads) распространяет готовые сборки.
Комплект не содержит библиотек Autodesk Revit API, моделей пользователей, авторизации или переписки.
