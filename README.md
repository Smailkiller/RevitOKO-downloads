# RevitOKO 0.1.1 — проверка обновлений

RevitOKO **0.1.1** добавляет кнопку проверки обновлений.
Пользователь скачивает [готовый установочный ZIP](https://github.com/Smailkiller/RevitOKO-downloads/releases/latest/download/RevitOKO-Windows-SDK-Autonomy.zip).
Коллеги могут скачать архив без аккаунта GitHub.
Пользователь также может открыть [релиз v0.1.1](https://github.com/Smailkiller/RevitOKO-downloads/releases/tag/v0.1.1).
Пользователь выбирает готовый ZIP из раздела **Assets**.
Архивы **Source code** не устанавливают приложение.
Пользователь один раз устанавливает версию 0.1.1 вручную при переходе с версии 0.1.0.

## Первое обновление до 0.1.1

1. Пользователь сохраняет свою работу и закрывает RevitOKO и Revit.
2. Пользователь полностью распаковывает `RevitOKO-Windows-SDK-Autonomy.zip` в обычную папку.
3. Пользователь запускает `Install-RevitOKO.cmd` из корня распакованной папки.
4. Пользователь нажимает **«Установить»** в окне установщика.
5. Пользователь открывает RevitOKO через ярлык рабочего стола после установки.

Пользователь также может запустить `artifacts\host\RevitOKO.Setup.exe` внутри распакованного архива.
Пользователь сохраняет весь комплект вместе и не переносит установщик отдельно.
Установщик запускается напрямую и не требует изменения политики PowerShell.
Установщик сохраняет профиль ChatGPT и журналы приложения.
Установщик проверяет отсутствие работающих RevitOKO и Revit перед заменой файлов.

## Следующие обновления

Пользователь нажимает **«Проверить обновления»** в RevitOKO.
Кнопка работает без подключения Codex.
Приложение проверяет последний публичный релиз `Smailkiller/RevitOKO-downloads` без входа GitHub.
Приложение автоматически скачивает только более новую версию.
Приложение показывает прогресс и позволяет отменить загрузку.
Приложение проверяет контрольную сумму архива, манифест и файлы комплекта.
Проверка и загрузка не заменяют установленную программу и не прерывают задачу чата.

Пользователь завершает задачу чата, сохраняет работу и самостоятельно закрывает Revit.
Пользователь нажимает **«Открыть установщик»**, когда приложение подготовит обновление.
Приложение повторно проверяет комплект и условия запуска установщика.
Приложение открывает установщик и нормально закрывает собственное окно после успешного запуска.
Пользователь нажимает **«Установить»** в установщике.
Приложение не завершает процессы принудительно и не сохраняет модели.

Приложение скачивает следующие обновления после публикации более новой версии.
Приложение не предлагает установку равной или более старой версии.
Проверка SHA256 подтверждает целостность, но не заменяет цифровую подпись издателя.

## Требования и первый запуск

- Компьютер использует Windows x64.
- Компьютер содержит установленный Autodesk Revit 2019 или Revit 2023.
- Компьютер содержит установленный Codex для работы чата.
- Пользователь имеет аккаунт ChatGPT с доступом к Codex.
- Компьютер имеет доступ к интернету для Codex и проверки обновлений.

Установщик RevitOKO не устанавливает Codex и Autodesk Revit.
Пользователю не нужны Python, Node.js, .NET SDK или API-ключ OpenAI.
Пользователь выполняет вход ChatGPT внутри RevitOKO при первом запуске чата.
Revit может запросить разрешение при первой загрузке неподписанного дополнения RevitOKO.
Пользователь проверяет имя дополнения RevitOKO и выбирает **«Загрузить один раз»**.

## Работа с моделью

Пользователь вводит путь к модели в чат и нажимает **«Отправить»** или **Ctrl+Enter**.

> Агент, открой модель C:\Models\model.rvt и посчитай листы. Агент не должен сохранять модель.

Агент запускает Revit, открывает указанную модель и возвращает результат в чат.
Агент использует отсоединённую копию совместной модели для анализа.
Приложение показывает изображения внутри ответа и предоставляет кнопку **«Открыть файл»**.
Пользователь раскрывает **«Технический отчёт»** для просмотра фактических действий и ошибок.
Приложение не переносит подключения MCP и профиль Codex Desktop автоматически.
Администратор отдельно настраивает необходимые MCP в профиле RevitOKO.

## Данные приложения

Приложение устанавливается в `%LOCALAPPDATA%\Programs\RevitOKO`.
Приложение хранит профиль, переписку и рабочие данные в `%LOCALAPPDATA%\RevitOKO`.
Приложение сохраняет обновления и технический журнал в `%LOCALAPPDATA%\RevitOKO\updates`.
Установщик размещает дополнения в `%APPDATA%\Autodesk\Revit\Addins\2019` и `2023`.

## Проверки этой сборки

Независимый QA подтвердил **501 тест**, отдельный тест окна обновлений и прежний тест окна чата.
Проверяющий вызвал настоящий сервис обновлений из опубликованной DLL сборки 0.1.1.
Сервис обнаружил предыдущий публичный релиз 0.1.0 и корректно отклонил понижение версии.
Отдельный сетевой тест использовал явно заданную тестовую версию 0.0.0.
Сервис скачал настоящий архив GitHub и подтвердил контрольные суммы всех **477 файлов** его комплекта.
Проверяющий не запускал настоящий установщик этой сборки и не заменял установленное приложение.
Проверяющий не завершил нативное нажатие кнопки из-за сбоя управления окном.
Тест окна проверил поток обновления с подменёнными сервисом и запуском установщика.
Проверяющий не выполнял новые операции Revit API в задаче обновления приложения.

## Сборка из исходников

Разработчик с доступом получает исходники из [приватного репозитория](https://github.com/Smailkiller/RevitOKO).
Разработчик устанавливает .NET 8 SDK и запускает `Build-RevitOKO.cmd` из корня проекта.
Файл `Directory.Build.props` задаёт версию приложения 0.1.1.
Сборка использует `Revit_All_Main_Versions_API_x64` для Revit 2019 и Revit 2023.
Комплект не содержит библиотек Autodesk Revit API, моделей пользователей, авторизации или переписки.

Разработчик повышает версию в `Directory.Build.props` для каждой следующей сборки.
Разработчик публикует соответствующий тег `vMAJOR.MINOR.PATCH` и архив `RevitOKO-Windows-SDK-Autonomy.zip`.
